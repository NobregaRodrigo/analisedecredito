# Sistema de Análise de Crédito

## Objetivo
Esta aplicação web calcula o score de crédito de uma empresa com base nos 5 Cs do Crédito e sugere um limite de crédito mensal.

## Requisitos
- Navegador web moderno (Chrome, Firefox, Edge, etc.)
- Nenhuma dependência adicional; o sistema roda localmente apenas com HTML e JavaScript.

## Como abrir
1. Clone ou faça o download deste repositório.
2. Localize o arquivo `index.html`.
3. Abra-o diretamente no navegador, dando um duplo clique ou arrastando o arquivo para uma janela do navegador.
